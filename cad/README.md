# 书童设备外壳草模

这里提供 Fusion 360 Python 脚本，用来生成 `58 x 48 x 35 mm` 的书童设备外壳草模。当前版本是 V3：圆角外形、卡扣式两件装配、上盖主板支撑柱、下盒空腔、下盒 Type-C 半豁口、背面双磁铁槽，并给电池增加 5mm 厚度余量。

## 文件

- `shutong_enclosure_fusion.py`：Fusion 360 脚本，生成背壳托盘、前盖、定位柱、电池浅槽、相机凸台、补光灯孔、麦克风孔、USB 口。
- `export_shutong_stl_fusion.py`：Fusion 360 脚本，把当前模型导出为 STL。
- `stl/shutong_base.stl`：背壳 STL。
- `stl/shutong_lid.stl`：前盖 STL。

## 已采用的尺寸

- 外壳：`58 x 48 x 35 mm`
- 主板：`42 x 42 mm`
- 电池：`50 x 35 x 12 mm`，厚度按原 7mm 再增加 5mm 余量
- 侧壁厚：`0.8 mm`
- 底厚：`2.8 mm`，因为背面有磁铁槽，底面不能跟侧壁一样薄
- 背壳高度：`15 mm`
- 前盖高度：`12 mm`
- 前盖与背壳重叠：`2 mm`
- 装配结构：上盖内裙边插入下盒，左右两侧共 4 个低矮卡舌/卡窗；可加少量胶防松
- 外壳圆角：`8 mm`
- 相机孔：`10.5 mm`
- 相机凸台：`22 x 16 x 1.1 mm`
- 主板固定：4 个上盖内侧两段式短柱，粗肩直径 `3.0 mm`、高 `2.0 mm`，细定位柱直径 `1.6 mm`、高 `1.5 mm`
- 安装孔估算：孔中心距主板边缘约 `3.6 mm`
- 镜头中心估算：距主板左边缘约 `20.0 mm`，距主板下边缘约 `28.5 mm`
- USB-C 中心估算：距主板左边缘约 `15.0 mm`，只在下盒开半豁口，开口宽 `9.8 mm`、高 `5.8 mm`
- 背面磁铁槽：2 个 `10.4 mm` 直径、`2.2 mm` 深度圆槽，中心距 `22 mm`，适配常见 `10 x 2 mm` 圆形钕磁铁

## Fusion 360 使用方法

1. 打开 Fusion 360，新建一个设计。
2. 进入 `Utilities -> Scripts and Add-Ins -> Scripts`。
3. 点击 `+`，选择 `shutong_enclosure_fusion.py`。
4. 运行脚本。
5. 隐藏两个 `reference_*` 占位体后，运行 `export_shutong_stl_fusion.py` 导出背壳和前盖 STL。

## 第一版需要实测后微调

- 主板安装孔中心：脚本按板边内缩 `3.6 mm` 预设，对应变量 `inset`。如果实测孔距不同，必须先改这里。
- 镜头中心高度：对应 `camera_offset_x`、`camera_offset_y`。
- USB-C 口位置：对应 `usb_offset_x`、`usb_opening_w`、`usb_opening_h`。
- 电池厚度：对应 `battery_h`，建议再预留 `0.5-1.0 mm` 泡棉空间。
- 补光灯/LED/麦克风孔：脚本按照片估算，第一版建议先打样验证。
- 摄像头与背面元件高度：当前主板由上盖内侧 `5.0 mm` 短柱支撑，正面给镜头凸起留空间。

## 打印建议

- 材料：PLA 可验证结构，PETG/ABS 更适合长期使用。
- 层高：`0.16-0.20 mm`
- 壁线：侧壁很薄，建议 2 圈或使用 Arachne 墙生成；如果切片后局部缺线，再把侧壁调到 `1.2 mm`。
- 填充：`20-30%`
- 支撑：前盖相机孔/补光灯孔附近建议开启支撑；背壳通常可不加支撑。
- 摆放：背壳开口朝上打印；前盖外观面朝上打印会更好看，但相机孔内侧可能需要支撑。
- 固定电池：不要直接用硬夹压软包电池，建议用薄泡棉和双面胶/魔术贴。
- 固定磁铁：建议用 `10 x 2 mm` 圆形钕磁铁，装入背面槽后用 AB 胶/环氧胶固定；装配前确认南北极方向一致。

## 结构说明

这个草模采用前盖开孔、背壳承托的两件式结构：

- 主板靠近前盖，保证镜头、补光灯、麦克风离开孔近。
- 当前版按修改意见把四个短支撑柱放在上盖内侧；下盒不放主板支撑柱。
- 下盒是空盒结构，用来放电池、Type-C 充电板和走线；电池建议用泡棉和双面胶固定。
- 前盖带内裙边，与背壳形成 2 mm 套合。
- 下盒侧面预留 Type-C 半豁口，左右侧边有卡窗，前盖内裙边有卡舌，顶部有相机凸台。
- 卡扣只负责定位和基础锁止；如果要给孩子长期使用，建议在角落加少量热熔胶或结构胶防松，拆卸时用热风软化胶后再撬开。
